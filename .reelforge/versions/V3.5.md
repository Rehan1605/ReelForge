## 1. What Changed
- **Layer 1: Durable MongoDB `reel_jobs` Queue (`storage/job.py`)**:
  - Implemented schema for `reel_jobs` tracking `status` (`queued`, `processing`, `completed`, `failed`), `lease`, `claim_key`, `timestamps`, `result`, and `error`.
  - Added partial-unique index on `(claim_key, active)` to atomically prevent duplicate concurrent jobs for the same reel.
- **Layer 2: Atomic Job Claiming & Heartbeat Leases**:
  - Workers atomically claim jobs via `find_one_and_update` with an expiring lease (`lease.expires_at`).
  - Added `_LeaseRenewer` background thread extending leases during long pipeline steps (Whisper transcription, vision model inference, OneNote upload).
  - Stale jobs from crashed workers are recovered via `recover_stale_jobs()`.
- **Layer 3: Decoupled Standalone Worker (`processing/worker.py`)**:
  - Standalone worker process (`python -m processing.worker`) that polls `reel_jobs` collection and processes reels.
  - Added async `bot/notifier.py` enabling the worker to post live Telegram progress updates and final result cards.
  - Added `REELFORGE_EMBEDDED_WORKER` toggle in `config.py` (default ON for local single-process development, 0 for standalone worker mode).
- **Layer 4: Idempotent OneNote Publication (`storage/publication.py`, `onenote/writer.py`)**:
  - Publication slot claiming prevents duplicate OneNote pages across job retries or concurrent worker runs.
- **Layer 5: Telegram Bot Asynchronous Job Submission**:
  - Updated `bot/telegram_bot.py` to enqueue jobs into MongoDB and provide `/queue` command.
