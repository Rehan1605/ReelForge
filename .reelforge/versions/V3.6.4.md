## 1. Objective & Motivation

ReelForge's multimodal pipeline relies on OpenAI-compatible chat completions with base64-encoded image frames to analyze video frames. Previously, `processing/vision_analyzer.py` assumed `OMNIROUTE_BASE_URL` defaulting to `http://localhost:20128/v1` without dedicated vision endpoint overrides or CLI verification tools.

For cloud worker execution, the vision processing layer requires:
1. **Dedicated Endpoint & Auth Overrides**: Ability to point multimodal vision inference to a specialized remote vision provider (e.g. cloud vLLM, OpenAI, OpenRouter, Gemini vision gateway) via `VISION_BASE_URL` and `VISION_API_KEY`, while retaining fallback to `OMNIROUTE_BASE_URL` and `OMNIROUTE_API_KEY`.
2. **Endpoint Normalization**: Resilient URL handling that strips trailing slashes and avoids duplicate `/chat/completions/chat/completions` paths if operators supply full endpoint paths.
3. **Preflight Operational Verification**: A lightweight health check (`check_vision_gateway` / `--check-gateway`) to verify gateway reachability and authentication without needing to download a reel or sample frames.
4. **Strict Backward Compatibility**: 100% preservation of local loopback defaults and existing test assertions.

## 2. Key Changes

### A. Configuration Layer (`config.py` & `WORKER.env.example`)
- Added `VISION_BASE_URL`:
  - Defaults to `""`.
  - When unset, vision analysis seamlessly resolves `OMNIROUTE_BASE_URL` (which defaults to `OPENAI_BASE_URL` or `http://localhost:20128/v1`).
- Added `VISION_API_KEY`:
  - Defaults to `""`.
  - When unset, vision analysis seamlessly resolves `OMNIROUTE_API_KEY` (which defaults to `OPENAI_API_KEY` or `""`).
- Documented both variables in `WORKER.env.example` under optional AI configuration and secrets.
- Updated `tests/test_v34_worker_contract.py` to track `VISION_API_KEY` under `_SECRET_KEYS`.

### B. Vision Processing Layer (`processing/vision_analyzer.py`)
- **Import & Precedence**:
  - Imports `VISION_BASE_URL` and `VISION_API_KEY` from `config`.
  - Precedence in `call_vision_model`: `explicit base_url argument > VISION_BASE_URL > OMNIROUTE_BASE_URL`.
  - Precedence in authentication: `explicit api_key argument > VISION_API_KEY > OMNIROUTE_API_KEY`.
- **Endpoint Normalization**:
  - Handles trailing slashes via `.rstrip("/")`.
  - Detects if `target_base_url` already ends with `/chat/completions`, preventing duplicate path segments.
- **Preflight Connectivity Probing**:
  - Implemented `check_vision_gateway(base_url, api_key, timeout) -> tuple[bool, str]`.
  - Probes `{base}/models` first (lightweight GET request).
  - Falls back to minimal ping on `{base}/chat/completions` if `/models` is not supported (HTTP 404).
  - Distinguishes success (HTTP 200/400), authentication failures (HTTP 401/403), connection refused, and timeouts.
- **CLI Enhancements**:
  - Added `--api-key` option to CLI parser.
  - Added `--check-gateway` option for operator preflight testing.
  - Passed `api_key` through to `analyze_latest_reel(...)`.

## 5. Remaining Cloud Deployment Blockers

1. **Public HTTPS Reverse Proxy / Ingress**: Microsoft Entra ID requires an HTTPS public redirect URI for `/connect`.
2. **External Remote Gateway Credentials**: Selection and provisioning of production `OMNIROUTE_BASE_URL` / `VISION_BASE_URL` and API keys.
3. **Instagram Cloud Datacenter Ingestion**: Validating `yt-dlp` unauthenticated downloads from datacenter IPs.
4. **Container Orchestration**: `docker-compose.yml` or container spec to manage bot, standalone worker, and environment variables.
