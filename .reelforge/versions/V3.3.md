# ReelForge V3.3 — Per-User Microsoft OAuth & OneNote Writer

> **Release Period**: 2026-09-13 to 2026-09-14
> **Commits**: `87739d9` (*feat: add ReelForge V3.3 multi-user Microsoft OneNote*), `d8bebfe` (*fix: persist MSAL OAuth flow state for public client callback*)
> **Engineering Status**: Verified & Committed

---

## 1. What Changed
- **Multi-User OAuth Authorization Flow (PKCE)**:
  - Built `auth/oauth_server.py` and `auth/state.py` providing an automated loopback OAuth server for public-client authorization code flow with PKCE.
  - Implemented anti-CSRF signed state tokens carrying `telegram_user_id` and timestamp.
  - Added `storage/oauth_session.py` to persist in-flight OAuth sessions.
- **Per-User Token Cache in MongoDB**:
  - Encrypted MSAL token cache stored in `users.microsoft.token_cache` in Atlas.
  - Added silent-only token refresh via `GraphClient(user_id=...)`.
- **Per-User OneNote Publishing**:
  - `OneNoteWriter(user_id=...)` creates an `InstaBrain` notebook in the individual user's personal OneDrive / Office 365 account.
- **Telegram UX Commands**:
  - `/connect`: Generates personalized authorization link.
  - `/disconnect`: Revokes Microsoft access with confirmation prompt.
  - `/mestatus`: Displays current Microsoft connection status and account details.
- **MSAL Callback Flow Fix (`d8bebfe`)**:
  - Fixed issue where public-client MSAL callback lost flow dictionary across processes by persisting state to MongoDB `oauth_sessions`.
