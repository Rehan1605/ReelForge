> **Release Date**: 2026-09-11

> **Engineering Status**: Verified & Committed

---

## 1. What Changed
- **Ownership Schema in Brain Objects**:
  - Added `ownership` subdocument to Brain Objects:
    - `ownership.saved_by`: List of user IDs who have saved this reel into their library.
    - `ownership.archived_by`: List of user IDs who have archived this reel.
- **User-Scoped Operations**:
  - Multi-user library filtering (`get_user_brain_objects`, `search_user_brain_objects`): users only see knowledge they have saved.
  - De-duplication across users: if User B submits a reel previously processed by User A, the pipeline reuses the cached Brain Object and attaches User B to `ownership.saved_by` via `associate_user_with_brain()`.
- **Telegram Multi-Tenant Isolation**:
  - `bot/telegram_bot.py` registers every interacting user and passes `user_id` down through the pipeline.
