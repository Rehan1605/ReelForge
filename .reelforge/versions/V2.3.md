## 1. Context & Prior Versions Note
Between V1.0 (late August 2026) and V2.3 (September 3, 2026), early V2 prototypes (V2.0–V2.2) experimented with prompt variations and local LLM execution. These intermediate steps were consolidated into the V2.3 milestone.

## 2. What Changed
- **OmniRoute AI Gateway Integration**:
  - Replaced ad-hoc local model calls with a unified OpenAI-compatible gateway (`OMNIROUTE_BASE_URL`).
  - Standardized all LLM calls on `/v1/chat/completions`.
- **Multimodal Visual Analysis**:
  - Implemented `processing/vision_analyzer.py` extracting keyframes from downloaded reels using OpenCV/FFmpeg.
  - Introduced `prompts/vision_analyzer.txt` asking vision models (`llama3.2-vision`) to extract on-screen code, text, diagrams, and visual techniques.
  - Injected vision findings into domain extractors to dramatically improve coding, food, and gym knowledge extraction accuracy.
- **Provider-Agnostic Gateway**:
  - Commits `1e9deb2`, `e0f0ac4`, `c351496` configured provider abstraction, enabling zero-code swapping between Ollama, OpenAI, and Gemini.

- Still running in single-user mode.
- Local JSON storage remained the sole database.
