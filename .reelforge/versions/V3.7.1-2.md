# V3.7.1 + V3.7.2 — Fixed OpenRouter Text & Vision Gateway

**Status:** Implemented and verified (uncommitted)  
**Date:** 2026-11-01

## Objective

Use one fixed OpenRouter endpoint and the `openrouter/free` route for text
generation, evaluation, categorization/extraction, and FFmpeg-extracted frame
analysis. Keep audio transcription local through the existing whisper.cpp
adapter. No paid model or provider fallback is permitted.

## Implementation record

- `processing/openrouter_gateway.py` centralizes the fixed chat-completions URL,
  fixed model assertion, required API key, bounded retries, and sanitized HTTP
  and network errors.
- Text generation and evaluation use the shared client without model override
  parameters. Vision retains base64 image URL payloads and frame selection but
  uses the same fixed transport.
- Configuration uses only `OPENROUTER_API_KEY` for remote inference; the URL
  and model are constants in `config.py`.
- Vision failure is represented in pipeline results and user notification.
