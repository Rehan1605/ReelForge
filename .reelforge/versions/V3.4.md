## 1. What Changed
- **Layer 1: Root-Anchored Path Resolution**:
  - Modified `config.py` to define `ROOT_DIR = Path(__file__).resolve().parent`.
  - Converted `WORKSPACE_DIR`, `BRAINS_DIR`, and `PROMPTS_DIR` to support absolute paths and environment variable overrides while anchoring defaults to `ROOT_DIR`.
  - Updated all extractors (`processing/*_extractor.py`) to load prompts via `PROMPTS_DIR` rather than assuming relative execution from repo root.
- **Layer 2: Platform-Agnostic FFmpeg Resolution**:
  - Implemented dynamic fallback in `config.py`: on Windows (`os.name == 'nt'`), defaults to installed WinGet FFmpeg path; on non-Windows (Linux / cloud containers), defaults to empty string `""` so FFmpeg and FFprobe are resolved from system `PATH`.
- **Layer 3: Configurable AI Gateway Routing**:
  - Replaced hardcoded localhost assumptions with `OMNIROUTE_BASE_URL` and `OMNIROUTE_API_KEY` (with `OPENAI_*` aliases as fallbacks). Remote gateways can now be used simply via environment configuration.
- **Layer 4: Container Definition**:
  - Added `Dockerfile` and `.dockerignore` targeting clean Linux worker execution, excluding laptop dotfiles and local caches.
