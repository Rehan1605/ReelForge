## 1. What Changed
- **Stylized OneNote Notes**:
  - Completely redesigned `onenote/formatter.py` to produce modern, readable knowledge pages in Microsoft OneNote.
  - Added clean dark-theme styling, metadata badges (author, category, date, shortcode), syntax-highlighted code blocks, actionable checklists, and embedded thumbnails.
- **Duplicate Reel Detection**:
  - Implemented `get_cached_brain_object()`: if a reel was already processed, returns the cached Brain Object and skips redundant Whisper transcription and vision calls.
- **HTML Sanitization**:
  - Added `onenote/sanitizer.py` to scrub invalid XML/HTML characters and illegal title characters before submitting payloads to the Microsoft Graph API.
