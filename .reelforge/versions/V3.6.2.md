## 1. What Changed
- **Worker Workspace Generator (`processing/worker_workspace.py`)**:
  - Implemented `activate_worker_workspace()`: thread-safe via double-checked locking, creates private process-lifetime directory `WORKSPACE_DIR/workers/w-<pid>-<random_hex>/`.
  - Implemented `effective_workspace()`: dynamically routes all media reads/writes to the private worker workspace if activated (standalone worker mode), or falls back to the configured flat `WORKSPACE_DIR` for embedded/CLI modes.
  - Implemented `is_worker_isolated()`, `worker_id()`, `workspace_root()`, and `reset()` (test hook).
- **Standalone Worker Activation**:
  - `processing/worker.py::standalone_worker()` automatically invokes `activate_worker_workspace()` prior to starting the asyncio worker event loop.
- **Pipeline Component Routing**:
  - Updated `download/downloader.py` (`clear_workspace()`, `_download_with_ytdlp()`) to use `effective_workspace()`.
  - Updated `processing/transcriber.py` (`transcribe_latest_reel()`) to glob inside `effective_workspace()`.
  - Updated `processing/vision_analyzer.py` (`get_latest_reel_path()`) to glob inside `effective_workspace()`.
  - Updated `storage/brain_object.py` (`_latest_file()`, `_latest_thumbnail()`, `create_brain_object()`) to resolve media paths inside `effective_workspace()`.
- **Exact Prefix Cleanup Safety**:
  - Updated `processing/pipeline.py::_cleanup_reel_media()` to match only exact filenames `f"{reel_id}.*"`.
  - Eliminated broad prefix globs (`f"{reel_id}*.*"`) to prevent numeric prefix collisions (e.g. reel `123` deleting `1234.mp4` during concurrent processing).
- **Persistent Store & Cache Invariants Maintained**:
  - `BRAINS_DIR` (persistent Brain Objects) and `WHISPER_CACHE_DIR` (model weights) remain strictly outside the isolated workspace.
