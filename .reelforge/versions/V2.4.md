## 1. What Changed
- **Pipeline Fault Tolerance**:
  - Implemented graceful fallback when multimodal vision analysis fails (e.g. gateway timeout or invalid video codec), falling back to audio transcript + caption.
  - Added strict validation to `processing/categorizer.py` to prevent hallucinated categories from crashing the dispatcher.
- **State Safety & Atomic Writes**:
  - Replaced naive file writes in `storage/brain_object.py` with atomic write patterns (`tempfile.NamedTemporaryFile` + `os.replace`), preventing corrupted zero-byte JSON files during sudden process termination.
- **Prompt Refinements**:
  - Standardized extractor output formatting to guarantee parseable JSON schemas across text LLMs.
