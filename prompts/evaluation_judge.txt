## CRITICAL GROUNDING & AUDITING RULES
----------------------------------------------------------------------

1. SOURCE EVIDENCE IS AUTHORITATIVE:
   - Only judge the Brain Object against what is actually present in the source evidence (Caption, Transcript, Vision Analysis).
   - Never invent or assume facts outside the provided evidence.

2. MISSING EVIDENCE != INCORRECT EXTRACTION:
   - If an evidence modality is unavailable (e.g., transcript is missing or null, or vision analysis is missing or null), DO NOT penalize ReelForge for omitting details that were never available to it.
   - If only caption is present, judge completeness and grounding strictly against the caption.
   - If vision analysis is NOT present (null or empty), set `multimodal_utilization.applicable = false`, `multimodal_utilization.score = null`.
   - If transcript or vision analysis IS present, evaluate whether spoken / visual information was effectively captured.

3. DISTINGUISH OMISSIONS FROM HALLUCINATIONS:
   - Hallucination / Contradiction (Factual Error): Extracting claims, ingredients, steps, numbers, tools, or URLs that directly contradict or have zero support in the source evidence.
   - Acceptable Normalization / Paraphrase: Converting raw text into structured lists, fixing obvious transcript typos, or summarizing key points is NOT a hallucination as long as the meaning is faithful.

4. CATEGORY-SPECIFIC STRUCTURED EVALUATION:
   - Dynamically evaluate whichever structured schema is present for the assigned category (e.g., ingredients/steps for Food, camera settings for Photography, exercises/nutrition for Gym, financial terms/metrics for Finance, concepts/code/tools for Programming, destinations/itineraries for Travel, workflows/habits for Productivity, models/prompts for AI, movie details for Movies & Edits).

----------------------------------------------------------------------
## 7 EVALUATION DIMENSIONS (RUBRIC)
----------------------------------------------------------------------

Evaluate each dimension with an integer score and clear reasoning:

A. CATEGORY ACCURACY (Score: 0 to 10)
   - Does the assigned category fit the core theme of the Reel?
   - Score 9-10: Clearly correct category.
   - Score 5-8: Questionable / ambiguous topic overlap.
   - Score 0-4: Clearly incorrect category.
   - Set `verdict` to one of: "correct", "questionable", "incorrect".

B. GROUNDING & FACTUALITY (Score: 0 to 20)
   - Are all extracted claims faithfully supported by the evidence?
   - Penalize: invented ingredients, false steps, fabricated tools/URLs, incorrect numbers, contradictory claims.
   - Score 18-20: Flawlessly grounded, zero hallucinations.
   - Score 14-17: Minor unsupported detail or slight exaggeration.
   - Score 8-13: Major hallucinated items or altered facts.
   - Score 0-7: Critical fabrications or pervasive contradictions.

C. COMPLETENESS (Score: 0 to 15)
   - Did ReelForge capture the primary takeaways, instructions, and concepts from the AVAILABLE evidence?
   - Do NOT demand details that were absent from the source evidence.
   - Score 14-15: Captures all significant information.
   - Score 10-13: Captures main idea but missed a minor useful nuance.
   - Score 5-9: Missed significant steps or central takeaways present in source.
   - Score 0-4: Missed almost all core content.

D. SUMMARY & INSIGHT QUALITY (Score: 0 to 15)
   - Are title and summary clear, concise, accurate, and insightful?
   - Avoid rewarding empty verbosity.
   - Score 14-15: High quality, accurate, punchy, useful.
   - Score 10-13: Adequate summary with minor clarity or focus issues.
   - Score 5-9: Vague, generic, or poorly structured.
   - Score 0-4: Misleading or useless summary.

E. STRUCTURED EXTRACTION ACCURACY (Score: 0 to 20)
   - Are category-specific schema fields properly populated with faithful data?
   - Check category fields (e.g., dishes/ingredients/steps for Food, tools/key_concepts for Programming, etc.).
   - Score 18-20: Structured fields accurately extracted and categorized.
   - Score 13-17: Minor omissions or slight misplacement across fields.
   - Score 7-12: Major field inaccuracies or substantial missing structure.
   - Score 0-6: Empty or completely incorrect structured fields.

F. TAGS, TOOLS & RESOURCES (Score: 0 to 10)
   - Are tags descriptive and accurate? Are tools, apps, gear, websites validly extracted?
   - Score 9-10: Accurate, representative tags and precise tools.
   - Score 6-8: Mostly accurate, maybe 1 generic tag or minor omission.
   - Score 0-5: Irrelevant/misleading tags or fabricated tools/websites.

G. MULTIMODAL UTILIZATION (Score: 0 to 10, or not applicable)
   - If BOTH transcript and vision are absent/null: `applicable` = false, `score` = null.
   - If transcript or vision is present: `applicable` = true.
   - Score 8-10: Effectively utilized spoken audio / visual cues in extraction.
   - Score 5-7: Moderately utilized, missed some visible or spoken elements.
   - Score 0-4: Ignored critical visual / spoken evidence present in the analysis.
